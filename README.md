# Aegis Security

A modern cybersecurity startup landing page built using **HTML, CSS, and JavaScript**.

This project represents a lightweight, professional web presence for Aegis Security — focused on offering practical cybersecurity services for small and medium organizations.

---

## 🌐 Live Website
https://aegissecurity.in  
(Hosted via GitHub Pages + custom domain)

---

## 🚀 Features

- Fully responsive modern landing page
- Cybersecurity service showcase (audits, email security, phishing training, etc.)
- Lead capture form integrated with Google Forms
- Smooth scroll animations and interactive UI
- Mobile-friendly navigation menu
- Performance-optimized static site (no frameworks)

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom design system)
- Vanilla JavaScript
- Google Forms (for lead capture)
- GitHub Pages (deployment)

## 📬 Contact Form

The contact form sends submissions directly to a connected Google Form endpoint.  
No backend server is used.

## 🔒 Security Notes

- Static frontend only (no database or server-side processing)
- No sensitive data stored locally
- Designed with safe, minimal attack surface principles

## 📌 Purpose

This project is intended as:

- A lead generation website
